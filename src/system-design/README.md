# 🎨 نظام التصميم المعياري (Clean Design System)

تمت إعادة هيكلة وبرمجة نظام التصميم بالكامل وفق معايير **الكود النظيف (Clean Code Standards)**، ليكون بديلاً معيارياً ومنظماً بدقة لملف `src/app/variables/color.css` و `font.css`.

> 🔒 **تنبيه:** هذا المجلد معزول تماماً وموجود في `src/system-design/` **ولم يتم ربطه أو استخدامه في أي ملف من ملفات المشروع حتى الآن** حتى تراجعه وتعتمد استخدامه بنفسك.

---

## 📁 بنية المجلد والملفات (Directory Architecture)

```text
src/system-design/
├── tokens/
│   ├── colors.css           # لوحات الألوان، الخلفيات، والحدود للثيمين الداكن والفاتح
│   ├── spacing.css          # مقياس المسافات بقاعدة 1:1 بيكسل والتدرج الهندسي
│   ├── radii-shadows.css    # قيم الزوايا، مستويات الظلال، وحركات الترانزيشن
│   └── typography.css       # خطوط الويب والمحلية، والأحجام والأوزان
├── components/
│   ├── buttons.css          # الأزرار بمختلف أنواعها وأحجامها وحالات الـ Focus
│   ├── inputs.css           # حقول الإدخال، وحالات الخطأ والتحقق
│   └── cards.css            # الكروت والأسطح الزجاجية ومربعات الحوار
├── utilities/
│   ├── typography.css       # كلاسات سريعة للنصوص والأوزان
│   └── spacing.css          # كلاسات هوامش ومسافات وفجوات (Margins, Paddings, Gaps)
├── index.css                # نقطة التجميع الرئيسية للنظام بالترتيب الدقيق
└── README.md                # هذا الدليل
```

## ✨ معايير الكود النظيف المطبقة (Clean Code Applied):

1. **فصل المسؤوليات بدقة (Separation of Concerns):**
   - فصل التوكنز الأساسية (Tokens) عن كلاسات المكونات (Components) وعن كلاسات الأدوات (Utilities).
2. **التسمية والتوافق الكامل (100% Backward Compatible):**
   - تم الحفاظ على كافة أسماء المتغيرات الأصلية (`--colorPrimary`, `--bgMode`, `--mainBtn`, `--fs-md`... إلخ) لمنع أي كسر في واجهاتك.
3. **مقياس المسافات النظيف (1:1 Pixel Mapping):**
   - كل رقم يعكس قيمته الحقيقية بالبيكسل (`--space-1: 1px`, `--space-8: 8px`, `--space-24: 24px`...).
   - التدرج مقسم لأربعة نطاقات واضحة:
     - **الدقيق (+1px):** من 1 إلى 4 بيكسل.
     - **المتوسط (+2px/+4px):** من 6 إلى 20 بيكسل.
     - **المكونات (+4px/+8px):** من 24 إلى 48 بيكسل.
     - **الأقسام والصفحات (+8px/+16px/+32px):** من 56 إلى 128 بيكسل.
4. **تنظيم خصائص CSS وقابليتها للوصول (Accessibility & Consistency):**
   - ترتيب منطقي للخصائص (Display -> Dimensions -> Typography -> Visuals -> Transitions).
   - إضافة حالات `:focus-visible` للوحة المفاتيح.
   - دعم كامل للشاشات ولمتصفحات Webkit بتأثيرات الـ Glassmorphism.
