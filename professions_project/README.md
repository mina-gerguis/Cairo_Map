# مشروع قسم المهن والصيانة والخدمات الحرفية (Professions & Maintenance Standalone Project)

هذا المجلد يحتوي على كافة ملفات ومكونات وسكريبتات قسم "المهن والصيانة ودليل الحرفيين"، تم عزله وفصله من موقع خريطة القاهرة ليكون مشروعاً وموقعاً مستقلاً تماماً في المستقبل.

---

## 📁 هيكل الملفات والمجلدات

```text
professions_project/
├── app/
│   ├── services/
│   │   ├── page.tsx                    # الرئيسية لدليل الحرفيين والمهن والبحث والفلترة
│   │   ├── dashboard/page.tsx          # لوحة تحكم الحرفي/الفني وإدارة الطلبات والمعرض
│   │   ├── auth/
│   │   │   ├── login/page.tsx          # صفحة تسجيل دخول الفنيين والعملاء
│   │   │   └── signup/page.tsx         # صفحة إنشاء حساب فني أو عميل جديد
│   │   └── workers/[id]/page.tsx       # صفحة بروفايل الفني وتفاصيل أعماله والتقييمات
│   └── admin/
│       ├── services/page.tsx           # لوحة إدارة الفنيين من قِبل المسؤول (Admin)
│       └── service-providers/page.tsx # لوحة التحكم والإشراف الشامل لمقدمي الخدمات
├── database/
│   ├── supabase_services_schema.sql                 # جداول الفنيين، المعرض، والتقييمات
│   ├── supabase_providers_management_schema.sql     # صلاحيات الإدارة والحظر والتعليق
│   ├── supabase_service_features.sql               # ميزات الطوارئ، تسعير الخدمات، وسوق الطلبات
│   └── supabase_service_request_notifications.sql   # التنبيهات الفورية عند إرسال طلب خدمة
└── assets/
    └── cairo_services.png              # أيقونة وصورة القسم
```

---

## 🛠️ الجداول المستخدمة في Supabase

1. **`service_workers`**: بيانات الفنيين والمهن، سنوات الخبرة، التقييمات، والحالة.
2. **`worker_portfolio`**: صور وفيديوهات معرض أعمال الفني.
3. **`service_requests`**: طلبات الصيانة والخدمات بين العملاء والفنيين.
4. **`worker_reviews`**: التقييمات والمراجعات المتروكة للفنيين.
5. **`client_reviews`**: تقييمات الفنيين للعملاء.
6. **`open_job_board`**: سوق الطلبات المفتوحة التي ينشرها العملاء.
7. **`before_after_portfolio`**: معرض الأعمال قبل وبعد الصيانة.
8. **`service_price_estimates`**: متوسط الأسعار الاسترشادية للخدمات والحرف في مصر.

## 🚀 كيفية التشغيل والربط مستقبلاً
عند رغبتك في بناء وتدشين هذا المشروع كموقع مستقل:
1. أنشئ مشروع Next.js جديد باسم (مثلاً `professions-app`).
2. انسخ مجلد `app` و `database` المرفقين هنا إلى المشروع الجديد.
3. قم بتشغيل سكريبتات SQL الموجودة داخل مجلد `database` في قاعدة بيانات Supabase الخاصة بالمشروع الجديد.
